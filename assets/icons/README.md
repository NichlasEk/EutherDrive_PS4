# EutherDrive app icon

Generated with the built-in imagegen tool on 2026-09-29.

- `eutherdrive-master.png`: original generated artwork, 1254x1254 RGB.
- `icon0.png`: PS4 application icon, 512x512 RGBA PNG. Only resized and
  normalized to the required pixel format; the artwork is unchanged.
- `PROMPT.txt`: exact generation prompt.

The packaging script validates the format and copies `icon0.png` into
`sce_sys/icon0.png`, so this is the actual console application icon.
Package 0.12 introduces the icon and retains the 0.11 emulator implementation.
